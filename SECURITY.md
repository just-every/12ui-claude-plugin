# Security

Report vulnerabilities privately to [support@12ui.com](mailto:support@12ui.com).
Do not open a public issue for a suspected vulnerability.

This repository holds the 12ui Design plugin for Claude Code: a skill, the
configuration of one hosted MCP server, and the plugin's mod source. It must
never contain API keys, user data, or internal service configuration. The mod
and the skill reach only the destinations listed in the README.
